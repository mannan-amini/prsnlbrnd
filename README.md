# وب‌سایت پرسونال برند منان (MANAN.)

> **نسخه ۲ — پیاده‌سازی کامل بر اساس وایرفریم اختصاصی و سند توسعه**

این پروژه یک وب‌سایت شخصی و مجله ادیتوریال مقاله‌محور با تمرکز بر مدیریت، تصمیم‌گیری، ساختن تیم و توسعه کسب‌وکار است که با پشته مدرن **Next.js 15 (App Router)**، **TypeScript**، **Tailwind CSS** و کتابخانه گرافیکی **Three.js** پیاده‌سازی شده است.

---

## ویژگی‌های کلیدی پیاده‌سازی شده

1. **اجرای ۱۰۰٪ آفلاین و بدون وابستگی به اینترنت**:
   - تمامی اسکریپت‌ها، کامپوننت‌ها و استایل‌ها به صورت محلی لود می‌شوند.
   - هیچ درخواست CDN یا ردگیری خارجی وجود ندارد.
2. **فونت پیدا (Peyda)**:
   - مستقیماً از مسیر فونت‌های سیستم شما کپی شده و در مسیر `public/fonts` قرار گرفت.
   - شامل تمامی ۹ وزن فونت پیدا (`Thin`, `ExtraLight`, `Light`, `Regular`, `Medium`, `SemiBold`, `Bold`, `ExtraBold`, `Black`).
   - راست‌به‌چپ (`dir="rtl"`) با استانداردهای خوانایی متون طولانی (عرض مطالعه `68ch` و ارتفاع خط `2.05`).
3. **ریتم بصری و ۹ بخش وایرفریم**:
   - **هدر ناوبری**: شیشه‌ای و چسبان (`Sticky Navbar`) با جست‌وجوی زنده (`Ctrl+K`) و دکمه ارتباط مستقیم.
   - **ایندکس عمودی ۰۱ تا ۰۹**: پایش زنده موقعیت اسکرول کاربر با قابلیت اسکرول نرم.
   - **بخش ۰۱ — Hero**: زمینه سرمه‌ای تیره لوکس (`#0A101D`)، مجسمه شیشه‌ای سه‌بعدی انتزاعی با تعامل نشانگر و قابلیت چرخش با Drag، نورپردازی آبی ملایم، امواج ظریف `LineWaves` در پس‌زمینه و دکمه CTA دارای حاشیه متحرک `StarBorder`.
   - **بخش ۰۲ — An Open Journal**: ۳ کارت تعاملی موضوعی (تصمیم‌ها، آدم‌ها، سیستم‌ها) با تصویرسازی‌های مینیمال.
   - **بخش ۰۳ — Editor's Pick**: مقاله شاخص («آیا تصمیم درست همیشه نتیجه درستی دارد؟») با افکت سه‌بعدی `3D Card` و قاب اسکرول `ScrollExpand` و امکان بازکردن پنجره مطالعه کامل.
   - **بخش ۰۴ — Selected Writings**: گرید نامتقارن نوشته‌های منتخب با تصویرسازی‌های انتزاعی.
   - **بخش ۰۵ — Field Notes**: لیست ادیتوریال یادداشت‌های کوتاه با خطوط مینیمال و تاریخ شمسی.
   - **بخش ۰۶ — Open Questions**: آکاردئون تعاملی پرسش‌های باز همراه با موج‌های پس‌زمینه `Waves`.
   - **بخش ۰۷ — Reading Desk**: معرفی کتاب‌های کلیدی مدیریت (تفکر سیستمی، مدیر اثربخش، از خوب به عالی) با طراحی جلد شیک.
   - **بخش ۰۸ — A Thought**: جمله تأملی با تایپوگرافی بزرگ و المان سه‌بعدی منشور کریستالی چرخان.
   - **بخش ۰۹ — About**: کادر معرفی شخصی منان، سوابق (پرینترلند و دانشگاه تهران) و راه‌های ارتباطی.
   - **فوتر**: تیره با پیوندهای دسترسی سریع و شبکه‌های اجتماعی.
4. **صفحات مکمل**:
   - آرشیو مقالات با فیلتر دسته‌بندی و سرچ: `/writing`
   - صفحه خوانش تک مقاله با پیشرفت مطالعه: `/writing/[slug]`
   - آرشیو یادداشت‌های کوتاه: `/notes`
   - صفحه تفصیلی درباره منان: `/about`

## نحوه اجرای آفلاین

برای اجرای سایت در سیستم خود به صورت آفلاین، یکی از دو روش زیر را انجام دهید:

### روش اول (سریع):
کافیست فایل اسکریپت را در ترمینال اجرا کنید:
```bash
./start-offline.sh
```

### روش دوم:
```bash
npm run dev
```

سپس در مرورگر خود آدرس زیر را باز کنید:
👉 **`http://localhost:3000`**

## گام بعدی: انتقال به دامنه و هاست (Deployment)

این پروژه از همین حالا کاملاً آماده انتقال به دامنه اینترنتی شما است:

- **روش اول (Vercel / Netlify / Cloudflare Pages)**:
  پوشه پروژه را در یک مخزن Git (مثل GitHub یا GitLab) قرار دهید و در پنل Vercel دکمه Import را بزنید؛ تمامی فرآیند بیلد و انتشار روی دامنه شما به صورت خودکار انجام می‌شود.
- **روش دوم (هاست‌های سنتی و cPanel)**:
  کافیست با دستور `npm run build` خروجی را بیلد کنید یا با تنظیم `output: 'export'` در `next.config.mjs`، خروجی پوشه `out` را مستقیماً در `public_html` هاست خود آپلود نمایید.
